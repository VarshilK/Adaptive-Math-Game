# Conclusion Reflection - Jack

My main responsibilities were writing the 15 math questions and their answer choices, coding the hard questions and developing the timer feature. The questions were divided into five easy, five medium and five hard questions.

Something I am proud of is contributing both the question content and the timer. My hard-question code is shown in [commit 207fe98](https://github.com/VarshilK/Adaptive-Math-Game/commit/207fe984ba1dcd970930820cc14f034004c113da). I also worked on a separate game version containing the timer. Rohin later integrated the timer-related code with Liming's main game version.

GitHub made it easier to share my questions and code with the team. One difficulty was having separate versions of game.js that needed to be combined. This made it important to explain which parts I wrote and how they connected to the other features.

If I could do this project again, I would agree on the timer interface with the team before developing it separately. I would also check the wording and answer choices carefully and use issues and pull requests to make my contributions easier to follow.
