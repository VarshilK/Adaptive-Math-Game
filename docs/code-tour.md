The game starts by asking the player to enter their name. After that, the player begins answering math questions.
The questions are selected from the question bank, and the game checks whether each answer is correct or incorrect.
Based on the player's answers, the difficulty can change throughout the game. After five questions, the game shows a summary of the player's results.
The leaderboard also keeps track of scores. The player can restart the game and try again.

The main files work together to make all of this happen. The HTML creates the structure, the CSS controls how the game looks, and the JavaScript files handle the questions and gameplay.
