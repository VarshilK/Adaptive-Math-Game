Game Architecture

Overview
Our project is an Adaptive Math Diagnostic game. It gives players five math questions and adjusts the difficulty based on their previous answers.

Main Files

- index.html: Sets up the structure of the website, including the different sections of the game.
- style.css: Controls the design, colors, layout, and overall appearance.
- allquestions.js: Stores the math questions and answer choices.
- game.js: Controls the main gameplay, including selecting questions, checking progress, and showing results.
- answerchecker: Handles checking whether the player's answers are correct.

How the Game Works
1. The player enters their name and starts the game.
2. The game selects questions from the question bank.
3. The player answers each question using one of four choices.
4. The difficulty adjusts based on the player's answers.
5. After five questions, the game shows the player's results.
6. The player can restart and play again.
